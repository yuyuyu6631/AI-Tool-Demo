# 页面设计规范

> 本文档只记录当前代码已经落地的页面结构与真实路由行为。

## 1. 首页 `/`

### 页面角色

首页已经是当前主承接页，不再只是品牌展示页。

它同时承担：

- 搜索入口
- 筛选结果承接
- 热门/最新/免费/国产等视图切换
- 场景入口
- 热门榜单入口

### 当前模块

1. Header
2. 搜索表单
3. 分类导航 chips
4. 视图切换 tabs
5. 当前筛选 chips 与重置操作
6. 工具列表
7. 分页
8. 场景侧栏
9. 热门榜单侧栏
10. 工具提交入口
11. Footer

### URL 状态

首页当前通过 URL 查询参数承接目录状态，主要包括：

- `q`
- `category`
- `tag`
- `price`
- `access`
- `price_range`
- `sort`
- `view`
- `page`
- `tab`
- `source`

## 2. 工具目录页 `/tools`

### 页面角色

统一搜索、筛选和 AI 搜索承接页，是用户浏览工具目录的主要入口。

### 当前模块

1. Header
2. 搜索表单（支持普通搜索和 AI 搜索模式）
3. 分类导航
4. 视图切换 tabs
5. 筛选条件面板
6. 工具卡片列表
7. 分页
8. Footer

### URL 状态

通过查询参数承接目录状态，支持：

- `mode`（ai 模式切换）
- `q`
- `category`
- `tag`
- `price`
- `access`
- `price_range`
- `sort`
- `view`
- `page`
- `page_size`
- `source`

## 3. 兼容路由

### `/rankings`

- 当前不是独立榜单页
- 直接重定向到 `/`
- 榜单内容由首页右侧“热门榜单”区域和首页视图承接

## 4. 工具详情页 `/tools/[slug]`

### 当前页面目标

帮助用户快速判断“这个工具适不适合我”。

### 当前已落地内容

1. 返回结果入口
2. 工具基础信息
3. 官网跳转
4. 标签、价格、访问限制、平台支持
5. 编辑点评
6. 评论摘要与评论区
7. 场景推荐
8. 相似工具推荐

## 5. 场景页

### 场景列表 `/scenarios`

当前用于展示场景入口列表。

### 场景详情 `/scenarios/[slug]`

当前用于展示：

1. 场景标题与描述
2. 场景问题说明
3. 主推工具
4. 备选工具
5. 目标人群标签

## 6. 对比页 `/compare/[comparisonSlug]`

### 当前行为

- 支持 2 到 3 个工具横向比较
- 进入页面时会先做 slug 规范化
- 非规范 slug 会重定向到规范地址
- 非法 slug 或工具数不符合要求时返回 `notFound`

## 7. 免费福利页 `/deals`

### 页面角色

展示免费/试用工具的聚合入口，帮助用户快速发现可薅羊毛的 AI 工具。

### 当前模块

1. Hero 区域（"薅羊毛雷达"品牌）
2. 免费工具卡片网格（展示免费/试用状态、deal summary）
3. 侧栏（限制说明 + 查看全部免费工具链接）

## 8. 按任务搜索页 `/search`

### 页面角色

基于用户输入的任务描述，推荐相关场景并引导进入场景详情页。

### 当前模块

1. Hero 区域（语义搜索品牌说明）
2. 搜索表单（兼容读取 `?task=...`，提交到 `/tools?mode=ai&q=...`）
3. 推荐场景卡片列表（链接到 `/scene/{slug}`，不作为首页任务搜索的唯一承接）
4. 侧栏（三步法说明：理解任务 → 拆解步骤 → 进入场景页）

## 9. 场景详情页 `/scene/[slug]`

### 页面角色

展示单个任务场景的详细拆解和推荐工具组合。

### 当前模块

1. Hero 区域（场景标题、描述、常见误区警告）
2. 步骤三列网格
3. "下一步"区域（二级任务标签，链接到搜索页）
4. 对比工具网格（主推工具 + 备选工具）

## 10. 认证页 `/auth`

### 当前结构

1. 品牌说明区
2. 登录表单
3. 注册表单
4. 社交登录占位按钮
5. 已登录状态卡片

### 当前事实约束

- 当前存在基础账号认证
- 当前仍未接入第三方 OAuth
- 表单校验、提交中状态、错误反馈都已在页面中处理

## 11. 后台页面

当前后台前端已经落地以下路由：

1. `/admin`
2. `/admin/tools`
3. `/admin/tools/new`
4. `/admin/tools/[id]`
5. `/admin/reviews`
6. `/admin/rankings`
7. `/admin/match-plans`

### 后台当前职责

- 查看总览数据（含匹配方案统计）
- 创建和编辑工具
- 查看和删除评论
- 创建和编辑榜单
- 管理匹配方案（创建/编辑/发布/预览）

## 12. 引导页 `/guide`

### 页面角色

根据 URL 中的任务参数，自动跳转到工具目录页的 AI 搜索模式。

### 当前行为

- 读取 `?task=...` 参数
- 有 task 时跳转到 `/tools?mode=ai&q={task}&page=1&page_size=24`
- 无 task 时跳转到 `/tools?mode=ai&page=1&page_size=24`

## 13. 页面口径约束

- `/tools` 是独立的工具目录承接页，不再是兼容重定向
- `/rankings` 当前直接重定向到 `/`，榜单内容由首页承接
- 后台管理已落地，包含匹配方案管理
- 用户评论已落地
