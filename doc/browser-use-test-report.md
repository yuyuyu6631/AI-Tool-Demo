## 测试方法说明

本次测试使用 browser-use (AI 驱动的浏览器自动化工具) 进行探索性测试。与传统 Playwright E2E 测试不同，browser-use 通过自然语言指令控制浏览器，能发现脚本化测试难以覆盖的问题。

**适配说明**: MiniMax-M2.5 模型会返回 `<think>` 标签，通过 monkey-patch 剥离后可正常与 browser-use 集成。
