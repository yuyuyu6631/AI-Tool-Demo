# 星点评 MVP 改动记录与预期

## 文档目的

本文档记录当前仓库已经完成的关键事实、当前状态和下一阶段预期。

## 本轮已完成事实

### 1. 仓库主干已稳定

当前主干包括：

- `apps/web`
- `apps/api`
- `packages/contracts`
- `infra`
- `doc`
- `docs`

### 2. 前端能力已从”目录展示”扩展到”公开站点 + 后台”

当前前端已经具备：

- 首页主承接页
- 工具详情页
- 场景页
- 对比页
- 认证页
- 匹配页
- 免费福利页 (`/deals`)
- 按任务搜索页 (`/search`)
- 场景详情页 (`/scene/[slug]`)
- 后台总览、工具、评论、榜单、匹配方案管理页

### 3. 后端主路由已扩展

当前 API 已覆盖：

- 目录与首页
- 评论读取与提交
- 认证
- AI 搜索、推荐、Chat
- 抓取与解析入口
- 后台工具/评论/榜单/匹配方案管理

### 4. 数据模型已覆盖运营基本面

当前数据库模型已经覆盖：

- 工具目录 (已扩展支持 Head/Mainstream/Longtail/Hidden 内容分级策略)
- 分类与标签
- 榜单与场景
- 匹配方案与方案工具关联（关键词驱动推荐引擎）
- 评论与评分
- 抓取快照与更新候选
- 用户、会话与细粒度角色 (RBAC)

### 5. 前端路由与自动化测试

当前已新增具备：

- 前端全局 404 与兜底路由的修复与规范化
- 趋于稳定的 Playwright E2E 回归测试策略

### 6. CI/CD 流水线已建立

当前已新增：

- GitHub Actions CI（lint/test/build/docs check）
- Docker 镜像自动构建与推送（GHCR）
- 定时健康检查与安全扫描
- Alembic 迁移自动验证

### 7. 文档工作流已自动化

当前已新增：

- `npm run docs:sync`
- `npm run docs:check`
- `pre-commit` 自动刷新当前实现基线
- `docs/current-implementation-baseline.*`

## 当前实际状态

可以概括为：

- 前后端主干已经稳定
- 评论和后台管理已进入当前事实
- 匹配方案推荐引擎已落地（关键词驱动 + 加权排序）
- 免费福利页、按任务搜索页、场景详情页已上线
- 自动文档基线已经接入流程
- CI/CD 流水线已建立（lint/test/build/deploy/healthcheck/security）
- 细粒度 RBAC 权限控制已落地
- 公网部署已验证（子路径部署 + Nginx 反代）
- 抓取审核闭环和商业化仍未完成

## 下一阶段预期

### 1. 收敛类型和文档（进行中）

- 继续减少重复类型
- 保持正文文档与自动基线一致

### 2. 增强前后端服务健康保障（进行中）

- 适当补充后端长链路的业务测与单元测试
- 巩固系统的观测指标

### 3. 补抓取审核闭环（未完成）

- 让抓取结果进入可审可发的工作流

### 4. 补增长能力与生态（未完成）

- SEO / 专题 / 线索收集
- 结构化编辑点评

### 5. 推进内容深度与决策效率（未完成）

- 用户评论增强（结构化、投票、标签聚合）
- 个性化推荐引擎
- 工具选型问卷

详细规划见 `doc/17-未来方向.md`。
